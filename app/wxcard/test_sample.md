# 用 Markdown 做小红书图文卡片
**MD2Card 本地版** 把一篇 Markdown 变成一组好看的图文卡片，**离线可用**、批量导出。
---
## 一、核心玩法
1. 在左侧写 Markdown
2. 用 `---` 分页，或用「自动拆分」
3. 右侧挑主题、尺寸，一键批量导出
> 支持 ==扩展语法==、^高亮^、~~删除线~~、++下划线++、$E=mc^2$ 公式。
---
## 二、常用语法
| 语法 | 效果 |
| --- | --- |
| `# 标题` | 一级标题（可当封面） |
| `^高亮^` | 高亮文本 |
| `++下划线++` | 下划线文本 |
| `~波浪线~` | 波浪线文本 |
| `$公式$` | 数学公式，如 $E = mc^2$ |
- [x] 已完成的待办
- [ ] 未完成的待办
```js
// 代码块自动语法高亮
const cards = md.split("---")
.map((text, i) => render(text, i));
console.log(cards.length);
```
---
## 三、多平台批量生产
- **小红书**：3:4 竖版，首图做封面
- **抖音 / 快手**：9:16 竖版图文
- **视频号**：5:4 封面 + 长图
- **公众号**：一键复制内联样式进编辑器
---
## 四、开始动手
把这段示例替换成你的内容，右侧选个喜欢的主题，点右上角「导出」即可。
